# Security and Responsible Data Handling

## Reporting a vulnerability

Please do not publish credentials, personal data, or exploitable details in a public issue. For a security concern, contact the repository owner privately through the contact method on their GitHub profile.

## Data policy

- Never upload real customer, account, payment, or personally identifiable information.
- Never upload employer or client source code, proprietary SAS AML materials, internal configurations, or production extracts.
- Use synthetic or appropriately licensed public data only.
- Do not commit API keys, passwords, tokens, or local environment files.

## Scope

This is an educational demonstration and is not a production AML system. It has not been security-audited or validated for regulatory use.
