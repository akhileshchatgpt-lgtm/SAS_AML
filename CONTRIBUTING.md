# Contributing

Thanks for considering a contribution.

## Scope

This repository contains independent educational AML analytics examples. Contributions should be original, explainable, tested, and based only on synthetic or appropriately licensed data.

## Before opening a pull request

1. Open an issue describing the proposed change.
2. Keep changes focused and document assumptions.
3. Add or update unit tests for Python functionality.
4. Run tests locally: `cd python && python -m unittest -v`.
5. Do not include credentials, customer data, employer code, proprietary product files, or confidential business rules.

## Pull request checklist

- [ ] The change has a clear purpose.
- [ ] Synthetic sample data is used.
- [ ] Tests pass or testing limitations are explained.
- [ ] Documentation is updated.
- [ ] Demo thresholds are clearly labelled as illustrative.

## Code of conduct

Be respectful, constructive, and inclusive. Focus feedback on the work and its technical merits.
